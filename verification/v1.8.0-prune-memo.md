# Short radix paths for pruning memos

Forest pruning maintains an immutable mapping from original node IDs to
postorder output IDs. The general integer map traverses twelve radix levels
for every key. This increment adds a dedicated eight-level pruning memo for module-local
forest IDs below 65,536.
Larger keys delegate to the unchanged general map, including its exact-key
fallback. No node-ID range is removed or rejected.

Only the map import used by classification changes. The traversal order,
shared-DAG memoization, retained alternatives, rejected-family promotion,
node ordering and diagnostic behavior remain unchanged. The general integer
map and native allocator are unchanged. This is an internal implementation
change, not a language or command-line change.

`tests/mgnc/generate-prune-memo.py` derives the specialized radix structure
from the existing generator and checks the fallback substitutions explicitly.
Both paths retain immutable snapshots and the missing-value sentinel.

## Focused checks

```sh
python3 -B tests/mgnc/generate-prune-memo.py --check
python3 -B tests/mgnc/prune_memo.py
python3 -B tests/mgnc/prune_forest.py
sbcl --noinform --script scripts/test.lisp
sha256sum -c verification/SHA256SUMS
git diff --check
```

The map check reuses the independent existing boundary and persistent-snapshot
oracle, including 65,535/65,536, the full-map boundary, signed integer extremes,
negative-key errors, replacement and dense updates. The forest check compares
all output fields and root IDs with a recursive oracle and handwritten
anchors across 15 cases: sharing, forward references, dead children and
ancestors, alternatives, promotion and page boundaries. It also checks retained
source metadata. Both checks are included in the normal ASDF test operation.
Use `--compiler` to run them with a selected native compiler.

A diagnostic comparison does not replace the fixed-candidate functional and
performance acceptance required for the full version. Existing resource
limits and earlier failed observations remain unchanged. This increment does
not establish full-version acceptance or release publication.
