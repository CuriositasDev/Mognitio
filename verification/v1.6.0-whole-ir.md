# Whole-project lowering

The experimental compiler now accepts silent, read-only `lower` for source
files and project manifests. It produces typed slot operations and control-flow
graphs for every checked body, including unused templates, nested functions,
unreachable operations and non-completing operands. Independent verification
checks source correspondence, capture propagation, definite assignment,
current-subject variant guards and lexical-owner Result reconstruction.

The [identity and observations](v1.6.0-whole-ir.json) bind the immutable
[adaptive-growth seed](v1.6.0-seed4.md), compiler source inventory and artifact.
The complete 102-file reference C0 and the full new compiler C1 both pass
lowering and verification. These exploratory observations passed the 900-second
guard; they are not adopted formal performance budgets.

## Checks

- 11 fixed lower fixture groups pass, including a 131,073-scalar literal,
  binary/path constructs outside the native subset, unused source, never-run
  side effects and a rejected unreachable type error.
- Existing semantic coverage passes: 59 cases, 36 flow cases / 154 checks,
  and 139 conformance checks through the new lower command.
- Internal probes accept six valid controls, including reordered IR IDs and
  source IDs, and reject 21 deliberately corrupted IR/dataflow cases with
  the expected internal diagnostics. Signals and timeouts are not passes.
- Complete normal suite: 236 Lisp groups, 605,733 assertions, 1,316 native
  processes and every subsequent Python integration pass with zero failures.
- C0 bytes remain equal to the fixed reference tree. C1 source matches its
  recorded commit; lower produces no output artifact. The fixture runner also
  checks read-only behavior against before/after input snapshots.

python3 tests/mgnc/v160-internals.py --seed VERIFIED_SEED/bin/mgn
python3 tests/mgnc/v160-lower-cases.py --compiler A --mode lower --output NEW_DIRECTORY
python3 tests/mgnc/v150-semantics.py --compiler A --command lower
python3 tests/mgnc/v150-review-flow.py --compiler A --command lower --evidence NEW_DIRECTORY
python3 tests/mgnc/v150-conformance.py --compiler A --command lower --evidence NEW_DIRECTORY
A lower C0/mognitio.toml
A lower compiler/mgnc/mognitio.toml
sbcl --noinform --script scripts/test.lisp

~~~

Build still uses the previously supported scalar native backend. This increment
does not claim the expanded native runtime, complete v1.6 implementation,
final-candidate acceptance, formal performance acceptance or release.
