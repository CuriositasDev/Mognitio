# Mognitio 1.4.0 performance acceptance

The same frozen executable is used throughout the [implementation acceptance](v1.4.0.md).
The reference CPU is Intel Core i9-10850K, Ubuntu 26.04, non-root. The
[environment](v1.4.0/environment.json) records kernel, governor, memory, swap,
filesystem, limits, affinity, load and sequential run commands.

## Formal matrices

Every input has one correct warm-up and five measured runs. Wall time includes
startup, reading, parsing/building, diagnostics and exit; wait4 measures each
child's peak RSS. Hashing and seed builds are excluded. No failed, timed-out or
slow valid sample was discarded.

| Matrix | Inputs | Samples | Wall budget | RSS budget | Result |
|---|---:|---:|---|---|---|
| C0 | 25 | 150 | file median 30 s; round-sum median 120 s | 512 MiB | pass |
| C1 | 56 | 336 | file median 30 s; round-sum median 120 s | 512 MiB | pass |
| Parse scale | 35 | 210 | cell median 30 s | 512 MiB | pass |
| Native build | 21 | 126 | cell median 30 s | 256 MiB | pass |

Corpus totals sum every startup within each round before taking the median.
The 120-second timeout is distinct from the budget. Negative cells require the
expected phase, byte span and scalar location to count as correct.

C0 round-sum median: **9.946 s**. C1: **19.651 s**.
Slowest parse input: `C1/compiler/mgnc/src/Width/width.mgn`, **1.933 s**.
Maximum measured parse RSS: **25.793 MiB**.

## Development measurements

Earlier prototypes reached the 120-second timeout on large or deep sources.
Linear history lookup, full-page reconstruction on each append, and experimental
node-byte/index representations were evaluated and rejected. Buffered packing
and indexed conservative history resolved the measured bottlenecks. Preliminary
single-run timings are excluded from the formal matrix and its medians.
Two observer setup errors were corrected before the supplementary run; neither
changed compiler source or discarded a formal sample.
