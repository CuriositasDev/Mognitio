# Native allocator first-fit cursors

The generated runtime restarted every allocation search at the free-list head.
A long prefix of small free blocks was traversed again for each larger request.
In a diagnostic label-oracle run, 353 of 359 instruction samples were inside
that traversal. These samples identify work to investigate; they do not establish
a wall-time budget or a completed bootstrap.

[WholeFit](../compiler/mgnc/src/WholeFit/fit.mgn) reuses excluded prefixes while
preserving ordered first-fit selection. Sixteen slots cover physical sizes
32 through 152. Larger requests use sixteen two-way sets whose complete
size/cursor pairs move together. A larger request may reuse a prefix excluded
by a smaller owner; the reverse is forbidden.

Cursors point to incoming free-list links. Taking or splitting a block repairs
every cursor that referred to that block's removed next-link field.
[WholeSweep](../compiler/mgnc/src/WholeSweep/sweep.mgn) clears active cursors
before rebuilding and coalescing free blocks. A newly prepended arena has zeroed
scratch metadata, so it starts with cold cursors.

The scratch area precedes the arena bitmap. Existing context offsets, object
headers, helper interfaces, private ABI revision, failure ordinals and descriptor
semantics remain unchanged. Arena geometry accounts for the additional metadata
before checking the mapping cap; the bitmap and physical-block bounds remain
explicit header fields. No seed machine-code blob is copied.

## Independent emitted-code controls

The [emitter fixture](../tests/mgnc/harnesses/v180-fit-cursors.mgn) calls the
production Mognitio emitters. The [driver](../tests/mgnc/v180-fit-cursors.py)
resolves their records and executes those actual bytes in a separate child
process on Linux x86-64. An independent ordered-block model checks each selected
address, allocated size, and the complete remaining free chain.

The controls cover mixed and randomized sizes, both cache ways, promotion,
eviction, safe lower-bound reuse, owner removal, explicit invalidation, and
fresh arena insertion. Actual emitted mmap and sweep paths additionally check
metadata separation, bitmap/payload bounds, survivor flags, coalescing, live-byte
accounting, and first-fit selection after collection.

A test-only counter measures free-block visits without changing allocation
choices. Two alternating colliding sizes require only two cold prefix scans.
Increasing distinct sizes reuse the lower bounds. Removing the counter must
leave selections unchanged. Cache-disable, both wrong-owner, half-promotion,
owner-repair omission, explicit-reset omission and sweep-reset omission mutants
must be rejected. Mutation membership is checked before expected rejection.
Dedicated terminal stubs distinguish allocator invariant failure and unexpected
collection from a test harness crash.

Run the focused controls with an already qualified compiler:

    python3 tests/mgnc/v180-fit-cursors.py --compiler /path/to/mgnc --output /tmp/native-fit-controls

The focused run passed 463 cases / 8,527 allocation requests and all seven
mutation controls. Full compiler and new-generation acceptance remain separate.

## Acceptance boundary

This changes emitted runtime bytes and invalidates earlier dependent generation
results. A new frozen source candidate must regenerate its compiler images and
repeat affected semantic, GC, resource/fault and full compiler regressions.
Whole-chain raw equality, all-generation/userland closure, inherited performance,
new preliminary/formal performance, archive restoration and release remain
separate gates. Focused allocator controls do not complete those gates.
