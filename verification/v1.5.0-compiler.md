# v1.5 Mognitio compiler implementation

This is the original candidate record. The later [flow review correction](v1.5.0-review-flow.md)
has separate source/artifact identities and does not replace these observations.

## Scope and stage

The experimental compiler implements shared project semantics for check and build.
Project analysis includes all discovered source files and required bodies.
Build consumes that same resolved result, validates its projection, then selects
the inherited native subset. Semantic rejection precedes native subset rejection.

Implementation and its required verification are complete. This record does not adopt a formal
v1.5 performance budget, accept the final compiler, or authorize a release.
The normal toolchain remains the published entry point.

## Functional and compatibility checks

The fixed artifact passed classification (20), public conformance (139),
cross-boundary cases (41), standard catalog (65), native generation/runtime (90),
inherited diagnostics (55), review regressions (63), parse cases (169),
normal-toolchain compatibility (4), parse CLI (21), parse faults (3),
parse mutations (6), project fault injection (14),
semantic programs (59), publication faults (9), and driver behavior (50).

Whole-corpus production checks passed for C0 and C1 with exit 0 and empty streams.
The first C0 observation exposed an RSS sampler race after successful compiler
exit. Its failure is retained separately. The repaired observer grants a bounded
100-ms exit grace, keeps the wall deadline, and fails sustained missing RSS.
Independent tests exercise both transient exit and ongoing monitoring failure.

The full normal toolchain suite passed: 232 Lisp groups, 34098 assertions,
1314 processes, zero failures, followed by the complete Python integration
sequence including 55 v1.5 path-inspection checks. Generator reproduction passed
for the catalog, IntMap, Unicode width data, storage, and grammar.

Internal input (51), declarations/imports (19), type formation (26 plus 86
mathematical boundary assertions), dependency graph (5), persistent map and ASCII
lookup checks passed. Native projection passed two valid cases and 13 corruptions.
The driver passed eight shared-analysis/snapshot/error-path checks. Reversed grammar
prediction with forced full classification passed all 20 classification cases.

An independent source scanner matched C0's 57 files, 615 declarations and 548
completed bodies, and C1's 102 files, 869 declarations and 729 completed bodies.
Both probes were built from S2 and produced identical instrumented binary hashes.
These diagnostic binaries are separate from A.

All seven whole-corpus mutation cases passed. The original width test selected
a digit in its declaration name; a focused corrected expectation selected the
literal with identical mutated input and compiler diagnostic. Both observations
are retained. Ubuntu 24.04 and 26.04 isolation passed C0/C1 analysis, no extra
compiler exec, unchanged inputs, and separate generated-program execution.

The inherited native resource gate passed all 21 cells and 126 samples
(one warm-up plus five recorded per cell). The largest recorded wall median was
17.906440 seconds and the largest measured peak RSS was 44.808594 MiB, within
the unchanged 30-second / 256-MiB limits. Every generated program result matched
its independent expected value.

The inherited parse resource gate passed 162 inputs and 972 samples: its
historical 25-file C0, the current 102-file C1, and 35 scale inputs.
The maximum per-input median was 1.180254 seconds and maximum peak RSS
28.367188 MiB. The C0/C1 round-total medians were 3.865699 / 11.588672 seconds,
within the unchanged 30-second per-input, 120-second corpus, and 512-MiB limits.
The inherited parse corpus C0 remains its original d14764bb revision; semantic
C0 is the separately fixed 4908a1a9 corpus. C1 source bytes agree across both gates.

All 118 preliminary cells completed one warm-up and three recorded runs
(472 fresh compiler processes), with correct positive/negative outcomes,
unchanged inputs, no cutoff and no monitoring failure. The 116 generated
scale cells and both complete corpora are retained separately.
