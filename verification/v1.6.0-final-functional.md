# Complete-backend candidate functional evidence

The public driver routes native builds through whole-project lowering, concrete
specialization, managed roots and the complete emitter. It accepts manifest
projects and verifies input/output identities before artifact publication.
Parse/check/lower retain their profiles and diagnostics.

[Identity and observations](v1.6.0-final-functional.json) bind the candidate to
173 sources and immutable S10. All project sources, manifest and metadata match
the public checkout. S10 reproduces the exploratory compiler byte-for-byte;
eleven functional gate groups already used those exact bytes and sources.

Validation:

- Expanded and inherited behavior, native profile, faults, publication bounds,
  two isolated userlands, lifetimes, forced-GC runtime and review cases pass.
- Both isolated userlands complete check/lower for all C0 and C1 sources.
- Independent lexical inventories match lowered membership: C0 has 102 sources,
  869 declarations, 729 executable bodies and 349 functions; C1 has 173 sources,
  1,210 declarations, 1,011 executable bodies and 581 functions. Unused
  declarations remain included.
- Internal probes pass metadata, dataflow, specialization, closure, helper,
  machine and root checks, including wide dataflow cases, complete-key duplicates,
  152 CFGs / 456 corruptions and 11 call-handoff corruptions.
- Six independent physical-heap retention witnesses pass; two intentionally
  retained-parent controls fail as expected. Two TrySite fixtures reject wrong
  Err descriptors, omitted allocation root points and missing payload roots
  using two independent root validators.
- Actual concrete request/type-interning order changes preserve ELF bytes.
- All 78 public-cost cells pass. The complete Unicode table is byte-identical to
  the independently verified 272-page / 1,112,064-scalar inventory.
- Normal suite at 4f2625dda8e94e0d5fddd9071ee193bba135e740 passes 243 groups,
  1,889,897 assertions, 1,324 native processes and all Python integrations
  through 55 path-inspection cases. Subsequent rebase adds seed evidence only.

Internal observations retain ordinary compiler modules, with recorded probe,
counter or trap differences. Raw streams, graph observations, rejected
experiments, harness setup failures and the prior candidate's failed native
performance are preserved. Isolation timings are functional observations.
Inherited performance, all preliminary cells, formal budget adoption and fresh
formal measurement remain pending. This is not whole-version acceptance or release.
