# Shared public type graph traversal

Public signatures can contain immutable type graphs with repeated child types.
The path-only cycle guard expanded these siblings repeatedly. A ten-level
four-way radix node graph prevented a dependent compiler build from completing
semantic checking within a 900-second exploratory guard.

The visibility checker now visits each type once per exposed signature using
an EQUAL hash set. It still checks all arguments, fields, variants and methods,
and keeps each declaration's origin and visibility checks independent.

Tested source: 1d093e7f74a29632b0641c86c4f94ddd8ade37c8.
[Machine-readable evidence](v1.6.0-public-signature-dag.json) records:

- A bounded visit-count regression fails promptly with the old walker and passes
  with the new one. A private leaf after the shared subtree is still rejected;
  independent whole-proof verification accepts/rejects the respective fixtures.
- Normal cumulative suite: 243 groups, 1,889,897 assertions, 1,324 native
  processes, and all Python checks through 55 path-inspection cases pass.
- The dependent exploratory compiler build now completes, with semantic
  checking taking 0.717 seconds. This is not a formal performance sample.
- Source review and git diff --check pass.

This accepts only the bootstrap checker repair. A replacement immutable seed,
fresh dependent compiler and whole-version acceptance are still required.
No Specification, Design contract or numeric acceptance criterion changes.
