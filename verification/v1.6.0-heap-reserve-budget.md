# Bounded native reserve within inherited memory criteria

The unchanged v1.5 C1 check fixture exposed a memory regression after proportional
arena reserve was introduced: the S7-generated compiler completed correctly but
reached 336,273,408 bytes RSS, beyond the retained 256 MiB limit.

The default native allocator now reserves one eighth of mapped heap, capped at
16 MiB, instead of one quarter capped at 64 MiB. The minimum arena, exact-size
cursors, first-fit order, single extension per allocation, explicit geometry and
heap caps are unchanged. A failed optional reserve mapping still retries reclaimed
space before reporting allocation failure.

Compiler revision tested: 59da2c98090302c90d3e1dcbd717695ade234aad.
[Identity and observations](v1.6.0-heap-reserve-budget.json) retain both the failing
observation and its successful counterpart. The same old input and compiler
source now complete in 97.96 s at 243,732,480 bytes RSS, within the existing
360-second median and 256-MiB limits for this exploratory observation. This is not
a substitute for the complete one-warm-up/three-run inherited performance gate.
The earlier observation took 64.37 s; the additional collections trade speed for
the required memory bound.

The complete 171-source C1 lower also finishes correctly in 556.23 s at
749,858,816 bytes RSS, within the 900-second exploratory cutoff. These runs had
other verification active and are not formal performance samples.

Validation at the tested source revision:

- Retain one million cells while discarding another million: 3,000,002
  allocations, 32 collections, 112,132,096 mapped bytes. The independent
  48-collection limit is unchanged; the mapped limit is tightened to 128 MiB.
  The old policy fails this new memory assertion.
- Nearly full small heap: five collections and 2 MiB mapped, against 4,763
  collections under fixed 1 MiB geometry. All optional-mapping failure cases pass.
- Native compiler: 90 value, I/O, module and forced-GC observations pass.
- Normal toolchain: 242 groups, 1,889,890 assertions, 1,324 native processes and
  every subsequent Python integration check pass.
- Levi: 182 observations and 11 negative controls pass against this checkout.
- git diff --check passes.

The public performance criteria, language Specification and Design contracts are
unchanged. A new immutable bootstrap seed must be frozen and verified from this
accepted increment before final candidate acceptance; S7 is preserved.
Complete new preliminary measurements, numerical budget adoption, fresh formal
measurements and release remain separate outstanding stages.
