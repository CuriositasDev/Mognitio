this parser before the inherited scalar checker, IR and AMD64 backend.
The normal toolchain retains its existing backend and package contents.
This record covers implementation acceptance. No 1.4 release, tag or package
publication was performed.

## Acceptance results

- All 54 new and 55 inherited conditions pass, with no failed or unrun
  implementation conditions. See the [conformance ledger](v1.4.0-conformance.md).
- Syntax/boundary tests pass 169 variants, including exact spans; inherited
  source-profile and review runners pass 77 and 63 cases.
- Every C0/C1 file passes in six rounds. Four complete-file corruptions and a
  large Unicode trailing-location control have the expected results.
- Ubuntu 24.04 and 26.04 minimal userlands pass 162 complete-corpus parses and
  100 native compile/run observations without a seed, SBCL or fallback.
  These are separate userlands on the recorded shared kernel.
- Both prediction orders match the independent complete-family oracle.
  Handwritten goldens and group-erasure/family-deletion controls pass.
  Persistent arenas pass 1,500 records each and six invalid grammar controls.
- All five intentional compiler faults are detected: namespace reservation,
  unknown annotations, residual equality, gap joining and ordinary comparisons.
- All 116 formal parse inputs and 21 inherited native cells meet the original
  budgets; see [performance](v1.4.0-performance.md).
- The 26 supplementary ambiguity cells and 156 public samples pass, including
  all 1,024 independent argument alternatives in the 32-by-32 case.

## Normal toolchain and consumers

The complete suite passes 214 Lisp tests, 9,261 assertions and 1,266 process
observations, followed by all cumulative external checks through
`ACCEPTANCE_EDGES_OK checks=19`. The [complete log](v1.4.0/normal-toolchain.log)
includes CLI, runtime, numeric, binary-output and observer regressions.
The detached run retained its final success marker rather than a separate exit
status file. [Input equivalence](v1.4.0/normal-equivalence.json) verifies the
unchanged source and normal test inputs against the final revision.

An additional unused imported-witness input exposed an existing normal-toolchain
internal error, also reproduced with the fixed 1.2 seed. The exercised-witness
positive control passes both toolchains. The unused variant is retained as a
[known baseline limitation](v1.4.0/known-normal-witness.json), not counted as a
successful observation or claimed fixed by this parser change.

Lévi passes 182 observations and 11 observer controls. A development normal
payload passes analysis/LSP checks (19 examples, 22 tests) and excludes mgnc.
It is a development artifact, not a release archive. Its normal source digest
matches the final revision. Independent editor-client compatibility still follows
that client's own version table.

## Decisions and reproduction

Scalar pages buffer 16 records before packing; historical columns use binary
search and conservative origin reachability. These internal refinements address
measured prototype timeouts without changing syntax, candidate sets, corpus
coverage, command behavior or budgets.

Use the [source build instructions](../compiler/mgnc/README.md) and
[runner guide](../tests/mgnc/README.md). [Functional evidence](v1.4.0/functional.json)
records all commands and outcomes. Performance uses one warm-up and five measured
runs per input. Check the published evidence from the repository root:

~~~sh
python3 tests/mgnc/acceptance.py
python3 tests/mgnc/generate_grammar.py --check
python3 tests/mgnc/generate_storage.py --check
git diff --check
sha256sum -c verification/SHA256SUMS
~~~

Evidence replaces private paths with role placeholders, including encoded
diagnostics; original evidence hashes are retained in the identity record.
C1 parsing proves structural coverage, not self-recompilation or later semantic
checking milestones. Implementation integration and release remain separate.
