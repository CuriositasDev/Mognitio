# Mognitio 1.9.0 release verification

The Linux amd64 CLI, test runner and stdio language server use the native
self-hosted compiler. The Debian package and offline bundle contain the same
fixed-point executable. The [packaging guide](../packaging/README.md) describes
the frozen seed and source inputs, the independent B/C generations, package
construction, external signature verification and installation.

The implementation passed the 1.9 and inherited 1.8 acceptance cases before
three follow-up corrections. The final implementation review covered inherited
pipe flags and diagnostic recovery in the runner. That revision passed 262
source regression tests, 17,018,030 assertions and the subsequent integration
drivers. Its independently generated compilers matched byte for byte, and the
Debian and offline payloads passed the affected runner, CLI and LSP checks.
[Final implementation review](https://github.com/CuriositasDev/Mognitio/pull/227)

For release artifacts, verify the signed manifest for the release commit before
extracting the offline bundle. The Debian package is also distributed through
the project’s signed APT repository for Ubuntu 24.04 and 26.04 amd64.
