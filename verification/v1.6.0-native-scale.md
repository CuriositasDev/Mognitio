# Native scale preparation

Large control-flow graphs now use a per-read predecessor reachability oracle for
root verification. Writes stop propagation of the previous value, while reads
at the same operation are seeded separately. The verifier does not reuse the
producer's fixed-point transfer equations. The former forward-path oracle is
retained only in tests.

The scanner splits source strings into balanced fragments before decoding their
scalars. This removes repeated slices from increasing offsets in the original
large string. The generated Unicode table now spells non-ASCII characters as
escapes, avoiding its million-distinct-character width-cache path. Its decoded
values are unchanged.

The [identity and observations](v1.6.0-native-scale.json) fix the complete
168-source probe, seed, driver override and executable. Compiler sources are
from 7ba6b7f; the following record commit also corrects the standalone boundary
fixture's required namespace and diagnostic-format assertion. That corrected
fixture was rerun separately. Compiler and normal-suite sources are unchanged.

## Validation

- The original forward oracle and the replacement both accept 52 production
  frames and 128 synthetic graphs, including cycles, empty/disconnected blocks,
  simultaneous reads/writes, terminator reads and bitmap word boundaries.
  All 384 flipped-bit controls and the existing 17 root/layout mutants fail
  with their expected internal diagnostics.
- Independent Unicode decoding checks all 1,112,064 valid scalar values and
  all 272 pages. The generated file is reproduced byte-for-byte.
- All 54 paired source-boundary checks have identical exit, stdout and stderr.
  The existing lexer checks also pass 10 valid, 18 invalid and eight residual
  operator cases.
- The same probe passes 41 native value cases, 26 I/O observations, six module
  cases, 17 collection-before-allocation cases, 26 resource/fault observations
  and 31 native-profile cases.
- The complete normal suite passes 236 groups, 605,733 assertions, 1,316 native
  processes and every subsequent Python integration. Whitespace checks pass.
- The 256-specialization fixture now builds and runs correctly. Its exploratory
  build took 317.94 seconds with 150,680 KiB peak RSS; the earlier forward-index
  probe reached the 900-second cutoff. These concurrent exploratory runs are
  not serial formal measurements or an adopted performance budget.

## Remaining whole-project work

The complete 168-source probe still reaches the 900-second exploratory cutoff
during whole-project lowering. All 168 files parse individually, but this does
not substitute for whole-project check/lower acceptance. The timeout is retained
as a failed observation. Further investigation of cumulative project parsing
and allocation cost is required.

The public driver still uses the previous backend. Public activation, final
same-candidate conformance/isolation/regression, all scale cells, formal budget
adoption and fresh formal measurements remain pending. This increment does not
mark v1.6 complete or released.
