# Runtime helper contracts and emitted dependencies

I/O adapters were treated as callable globals outside the helper registry, and
terminal entries were not represented there. The registry now includes active
I/O adapters, terminal handlers and their dependencies, argument/result kinds,
allocation/failure effects, clobbers and fixed root-descriptor labels.

A separate pass compares the emitted helper references with the declared
dependency graph, checks linked root descriptors, and rejects undeclared
cross-helper edges. Metadata validation checks transitive allocation/failure
effects through dependency edges and distinguishes nonreturning terminal
entries from the returning callee-save convention. All helpers emitted by the
current backend remain present; this does not introduce dead-code elimination
or a general machine-code proof.

assertions, 1,324 native processes and all Python integrations.
