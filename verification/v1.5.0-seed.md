## Restore and verify

The archive is retained in the internal seed store, not published as a release.
Use an explicit archive and external receipt path:

~~~sh
python3 tests/v150-seed.py --bundle <seed-store>/lisp-f0e582da5f97467544e861d0ad3390b2cd9776b4.tar.gz --receipt verification/v1.5.0-seed.json
python3 scripts/freeze-seed.py --verify <restored-seed>
~~~

The restore test passed: 709 components verified, modified launcher rejected,
metadata API run and build succeeded in an isolated filesystem without host
compiler/source/libraries, and the generated ELF ran with no seed or Lisp present.
The safe tar extraction removes group-write permissions; the test restores the
declared file modes only after checking the manifest digest against the receipt.

`scripts/freeze-seed.py` records the exact source revision, build command,
non-secret environment, runtime inputs, dependency versions and every component
path/size/mode/hash. A new build may produce a new archive identity; the existing
fixed archive must be retained and verified rather than silently regenerated.

This seed freeze does not imply completion or acceptance of the dependent
Mognitio compiler, performance budgets, self-rebuild or release.
