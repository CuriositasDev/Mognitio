## Harness validation and reproduction

The formal CLI rejects partial cell selections and mismatched identities before
invoking A. It returns failure for a missing/failed run or an exceeded budget and
preserves unsuccessful observations. The 44-check budget harness covers inclusive
boundaries, excess wall/RSS, bad identities, incomplete membership, failed warm-up,
and the actual CLI's failure exit. The existing measurement harness covers Linux
wait4, streams, time/RSS, exit races and unavailable observations.

The normal toolchain suite passes at the measurement implementation revision:
232 Lisp groups, 34098 assertions, 1314 processes, zero failures, plus all Python
integration checks. [Commands and exits](v1.5.0-formal-performance/normal-suite.json)
and the [sanitized full log](v1.5.0-formal-performance/lisp.log) retain the result.
Compiler sources and the seed have not been modified by the harness change.

Restore the fixture bytes matching the published manifest and use the verified A:

~~~sh
python3 tests/mgnc/v150-budget-harness.py
python3 tests/mgnc/v150-measure-harness.py
python3 tests/mgnc/v150-measure.py --compiler VERIFIED_A --fixtures FIXED_FIXTURES --output NEW_FORMAL_DIRECTORY --formal-budget verification/v1.5.0-formal-performance/budget.json
~~~
