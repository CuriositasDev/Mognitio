# Reader storage and bitmap emission

Repeated immutable reads in parsing and root analysis copied iterator buffers,
paged payloads and intermediate Result values. Readers now select the original
page group and lane directly; chart buckets, prediction lists and root-point
lists use checked indexed reads. Bounds, traversal order and diagnostics remain
unchanged. Dataflow and root analysis use the existing persistent PruneMemo map,
and bitmap construction reuses the pending-word editor.

Root bitmaps emit signed 64-bit fields instead of constructing each byte
separately. The native encoder preserves the same little-endian bytes, including
the high bit. REX prefixes append directly to the pending byte sequence.
Contract mutation tests cover both byte records and word records, retaining
the nonzero managed-receiver control. The forest golden projection recognizes
type names and package application spelling; independent full-family comparisons
are unchanged.

## Validation

The exact 296-file compiler source passed 11 affected functional jobs and four
additional storage/projection cases. Coverage includes full record payloads,
page and group boundaries, invalid-index diagnostics, persistent snapshots,
bitmap and dataflow mutation controls, root reachability, structural parse
families, native verifiers, runtime labels and independent encoder bytes.
The four additional cases check 11 arena errors, two page bounds, 18 storage
errors, five routing paths, nine full records, 36 direct projections, 50 bitmap
expansions and the expected integer-overflow failure.

Three fresh native generations agreed byte-for-byte with the initial native
compiler, including a generation produced by the hosted compiler. All four
native artifacts have mode 0755. Six saved outer/inner observations were
independently checked, including process collection and ownership release.

A fixed four-case comparison fit its existing budgets, with whole-project
lowering close to its limit. This is diagnostic evidence only. Earlier failures,
unrun cases and unadopted results remain retained; no formal performance pass is
claimed. Fresh acceptance from integrated main, full P0/P1 coverage and final
archive restoration remain separate gates.
