# Mognitio 1.4.0 implementation review correction

The reviewed `b4c84bce66bb2cc684a47d60c99e5a1654e4dd76` snapshot had two defects:
a valid two-comparison argument list was rejected before declaration guards ran,
and the combined parse workload measured 127 extra blocks instead of 128.
This record supersedes those conclusions in the [original acceptance](v1.4.0.md).
The accepted source behavior and numeric budgets are unchanged.

## Native comparison arguments

For a function accepting two Bool arguments and a local `a: Int = 1`,
`choose(a < 2, 3 > (1))` now builds and returns 7, as does the explicitly grouped
`choose((a < 2), (3 > (1)))`. The [old observations](v1.4.0-review/baseline-reproduction.json)
retain the original rejection and successful grouped control.

Build now evaluates runtime-name guards on the shared forest before projection.
A rejected child invalidates its containing family; a surviving alternative keeps
the owning symbol, prefix and source span. Scoped declaration intervals preserve
initializer visibility, parameters and sibling block boundaries. Unresolved names
needed to choose a native interpretation receive semantic diagnostics without being
silently classified as runtime values or templates. Parse keeps all candidates.

[Twenty paired cases](v1.4.0-review/classification.json) compare the repaired compiler
with 1.3: grouping, spacing, case renaming, parameters, mutable bindings, nested calls,
argument blocks, multiple ambiguous pairs, and three missing-name/scope controls.
The invalid comparison chain remains a parse error. Negative phases and spans match
1.3; diagnostic wording is not required to be identical.
The same cases also pass with [reversed grammar prediction](v1.4.0-review/order.json).

## Regression scope and evidence gate

The [18 command results](v1.4.0-review/functional.json) include all 169 syntax variants,
77 inherited source cases, 63 review cases, native differential execution, driver and
fault cases, and independent 24.04/26.04 userland runs. Both userlands share a kernel;
this does not claim two independently booted operating systems.
All 82 corpus files passed in both userlands (164 observations),
with 100 native compile/run cases. The formal parse matrix has 702
processes and the native matrix has 126 builds plus execution checks.

The [normal toolchain suite](v1.4.0-review/normal-suite.json) completed with 214 tests,
9,261 assertions, 1,266 processes and the cumulative external acceptance suites.
This run retains both the complete raw log and a separate exit-status record: exit 0.
Unchanged normal runtime, consumer, storage and parser-oracle evidence remains linked
from the original record and is reused only for matching source hashes. The known
unused imported-witness baseline limitation remains unchanged and is not claimed fixed.

`python3 tests/mgnc/acceptance.py` checks the original snapshot as historical evidence,
then requires this correction's current source identity, observed results, independently
verified shape, full current corpus and every formal sample. It does not accept an old
compiler's measurements as evidence for the new executable.
