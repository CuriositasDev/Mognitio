# Repeated native generation evidence foundation

The experimental generation harness records immutable candidates, producer
edges, exact output bytes and modes, per-attempt observations, and independently
versioned regression expectations. It does not replace the normal toolchain.

A source manifest includes every file, including unused modules and generated
tables. Its inventory is rechecked before generation and after execution.
Native edges mount one verified producer and the whole input source read-only
in a fresh non-root namespace; only bootstrap mounts the frozen Lisp seed.
Outputs start empty. Bootstrap A retains the Lisp publisher mode 0700; native
outputs use mode 0755 under the fixed 0022 umask. The verifier does not change
compiler artifacts to make their modes match. A failed command, cutoff, observation failure, changed
input, or remaining child cannot produce an accepted artifact.

The raw comparator independently detects bytes, length and mode changes.
Equal hashes do not merge generation roles or producer relationships. Suite
evaluation preserves missing cells as NotRun and retains unsuccessful attempts.
Filesystem ledgers retain binary names, modes, symbolic links and hardlink
relationships for restoration checks. Content-addressed archives store regular
blobs separately from filesystem metadata, so restoration does not reinterpret
symlinks or discard non-UTF-8 filenames. Restore verifies every blob and the
complete ledger, and refuses existing destinations or archive tampering.
Source and ledger walks propagate directory enumeration failures instead of
silently omitting inaccessible descendants. Missing or linked ledger roots are
rejected. The archive writer refuses an unreadable subtree before creating an
archive; it never grants itself permission or calls an incomplete copy restored.

The fresh observer retains the existing command wall and kernel RSS accounting,
adds the full sampled RSS series, and runs each observation in a new process.
RSS sampling sums the command and its descendant tree, including namespace
wrappers; shared pages may be counted once per process. Namespace execution
uses the target as PID 1 so a successful command does not orphan an intermediate
reaper. Controls exercise 96 MiB inside the actual namespace and RSS cutoff cleanup.
Its kernel peak includes the fixed worker floor; it does not subtract that floor.
Missing short-process samples are null, not zero memory. Descendants that exit
between procfs reads are recorded as unavailable samples. Each worker executes
a frozen copy of its observer sources, so a concurrent checkout cannot remove
its code or relabel a completed observation with newer source bytes. Controls cover failure
streams, wall/RSS cutoffs, child cleanup, and retained/freed controller memory.

```sh
python3 tests/mgnc/v180-evidence-tests.py
python3 tests/mgnc/v180-acceptance-tests.py
python3 tests/mgnc/v180-performance-tests.py
python3 tests/mgnc/v180-runner-tests.py
python3 tests/mgnc/v180-archive-tests.py
```

This foundation is not whole-version acceptance. Seed requalification, actual
full generation and repeated fixed-point comparisons, all-generation language
and consumer regressions, faults, both userlands, inherited performance, newly
adopted numerical budgets, and restored final evidence remain separate gates.
No release or ordinary toolchain migration is implied.

The strict execution evaluator additionally binds each cell to its generation,
producer graph, source, userland, measured target and independently fixed expected
record. It checks exact exit status, diagnostic fragments or bytes, recorded side
effects, clean terminal outcomes, and stdout/stderr hashes against the raw ledger.
A missing environment cell remains NotRun; a Passed label cannot override these
checks. Raw files must still be verified when assembling or restoring the archive.

Before admitting a saved tree-observer result, callers use
`validate_observer_binding` to compare the recorded request digest, worker digest
and exact dependency source set with the completed observation. This also checks
historical runs that predate frozen worker copies: a zero exit with different
start/end worker identities is rejected. Callers hash the actual saved request
and verify any frozen source bundle; identity validation alone does not establish
a successful terminal outcome or turn an old failed attempt into a passing one.

The inherited mapping validator derives A, S17, D0, D1 and generated-program roles
from the original command dependency graph. It rejects old-artifact substitution,
changed inputs or thresholds, missing cells, and dependency build time mixed into
a measured command. The caller supplies producer identities already admitted by
the generation graph; the validator does not create or execute those producers.
These controls do not establish completion of the required execution matrix.

The new performance scorer requires one valid warmup and three ordered, valid
recorded samples. It retains all recorded values, uses their wall median and
maximum of kernel and sampled tree RSS, and keeps a missing sampler value null.
Failed warmups, observer failures, leftover children, malformed measurements and
changed observer policies cannot pass. Purpose budgets must cover every unique
manifest cell with the same candidate and manifest digest. This numerical
validator does not adopt a budget, authenticate its adoption document, or turn
preliminary measurements into formal acceptance; callers verify that provenance
and the raw observations separately. Old cells keep their original policies.
