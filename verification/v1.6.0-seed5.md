# Explicit-capacity bootstrap seed

The expanded native compiler exhausted the host Lisp default 1 GiB dynamic
space during seed compilation. The seed freezer now records and embeds a
4096 MiB dynamic-space capacity and a 64 MiB control-stack capacity.
This affects the host seed process, not generated native heaps, source
semantics, or an adopted performance budget.

The [machine-readable record](v1.6.0-seed5.json) fixes a separate replacement
for the [previous seed](v1.6.0-seed4.md). Previous archives and observations
remain immutable. The tested implementation commit is
1f18f89fc793c4dc79b23af9e948cc3cc29719f3; the subsequent record commit changes
only these two verification documents.

## Validation

All 1,060 sealed components verify. Isolated restoration rejects a changed
launcher and passes host run, build, and standalone ELF execution.
All 17 fixed capability observations pass, including the full 102-file C0.
The complete normal suite passes 236 Lisp groups, 605,733 assertions,
1,316 native processes, and all subsequent Python integrations through the

This accepts a bootstrap prerequisite. Dependent compiler, runtime,
independence, and formal performance acceptance require their own candidate
identities and results. No release is performed.
