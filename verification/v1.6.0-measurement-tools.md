# Candidate-bound measurement tools

The scale generator now reproduces the frozen 34-case matrix, including the
combined project and repeated I/O workload. All 430 generated files match the
earlier frozen inputs byte-for-byte. The manifest SHA-256 remains
48c363bf4150f8492c92bf448cf6b77b5847d15f429f4690ac5fccf74d4fd094.

A frozen measurement manifest covers 103 units: whole C0/C1 check/lower, scale
lower/build and native execution at each dynamic input size. C0 must match the
fixed 102-source reference inventory. The runner separates fresh warm-up and
recorded runs, binds identities, preserves raw streams and unrun cells, rejects
nondeterministic or malformed artifacts and records per-run environment data.
A native run requires a successful measured build.

The observer reuses the tested wall/RSS monitor and additionally detects,
terminates and reaps orphaned descendants. Such a command is a harness failure,
including when its direct process exits successfully.
