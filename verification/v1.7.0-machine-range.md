# Bounded machine-verifier byte ranges

Whole-project verification often selects only a short prefix or suffix of a
large byte list. Traversing the entire list first materialized an unnecessary
iteration buffer for every such check.

Range selection now indexes only the requested overlap with the list. Negative
starts clamp to zero; ends beyond the list clamp to its length; inverted,
entirely negative and entirely out-of-range intervals remain empty. The
selected bytes and verifier diagnostic ordering remain unchanged.

The native tests extract the production function and compare it with a frozen
full-traversal reference and 320 independently generated expectations. They
cover empty and large inputs, both signed integer extremes and partial bounds.
Two boundary mutations must fail. A separate actual-native allocation control
checks every selected value while taking 256 short slices of 65,537 items.
The indexed path must allocate less than 8 MiB in total; full traversal exceeds
128 MiB. These are structural-work bounds, not formal time or RSS budgets.

Complete machine-verifier differential diagnostics, generated compiler
regression and whole-generation acceptance remain separate checks. This
increment does not change language behavior or declare version completion.
