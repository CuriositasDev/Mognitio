# Retain only reachable semantic parse-forest nodes

The inherited 102-source semantic C1 check exceeded its unchanged 256 MiB
RSS budget. The compiler returned the correct result in all four observations,
but its maximum RSS was 274,927,616 bytes. A fresh controller reproduced the
same compiler peak; inherited parent RSS did not explain this failure.

## Change

Header collection now applies the existing memoized forest pruning operation
with an empty rejection set before scanning each completed module.
This retains every node and alternative reachable from the completed root,
including shared subgraphs, while discarding nodes from failed parse paths.
The existing operation remaps child and alternative references and preserves
source tokens, positions, comparison records and item counts.

Header declarations are collected after the remapping, so their node IDs refer
to the retained forest. Public parse execution continues to use the original
structural parser. No syntax choice, visibility rule, budget, seed/runtime
implementation or language contract changes.

whole-corpus mutation runners against an image bound to the changed source.

its historical default expects native rejection and pre-creates a sentinel.

Run the complete repository test suite, checksum verification and diff checks
at the reviewed commit. Freeze a new candidate and regenerate the dependent
