# Complete-backend candidate functional evidence

The public driver now routes native builds through whole-project lowering,
concrete specialization, managed roots and the complete native emitter. Manifest
projects are accepted by build, and input/output identity checks precede artifact
publication. Parse/check/lower retain their own profiles and diagnostics.

[Candidate identity and observations](v1.6.0-final-functional.json) bind every
functional check to the 173-source compiler built by S9. The 173 compiler sources and project manifest are
byte-identical to the public-driver checkout; an alternate driver is not used.
Catalog metadata and regeneration inputs/tools are also inventoried. The staged
non-executable README retains its pre-activation description.

Validation:

- Eleven functional gate groups pass: expanded values, inherited native and
  semantic behavior, supported profile, fault injection, path/output boundaries,
  two isolated userlands, lifetime/resource observations, normal/forced-GC runtime,
  and review-specific module captures and differing Result success types.
- Both isolated userlands complete check/lower for the entire C0 and C1.
- Independent lexical inventories match lowered coverage: C0 has 102 sources,
  869 declarations, 729 executable declaration bodies and 349 functions; C1 has
  173 sources, 1,201 declarations, 1,002 executable declaration bodies and 582
  functions. Unused declarations remain included.
- Same-source internal probes pass metadata, source membership, dataflow,
  specialization, closures, helper/machine contracts and managed roots, including
  152 CFGs / 456 corruptions and 11 call-handoff mutations.
- Six physical-heap retention witnesses and two negative controls pass. Two
  targeted TrySite fixtures reject wrong return descriptors, false allocation
  projections and missing payload roots using independent validators.
- Runtime-owned module snapshots, nested type/value specialization, request-order
  stability and source-origin capture-load mutation controls pass.
- All 78 independent public-cost cells pass, and the full Unicode table matches
  272 pages / 1,112,064 scalar values.
- Normal cumulative tests pass at source revision
  496e8a92b6a45efc6e77256f2ceadf5966e2b972: 242 groups, 1,889,890 assertions,
  1,324 native processes and all subsequent Python integration checks.

The additional TrySite harness and this record do not change Compiler C1.
Its allocation effects are canonical derived data; a false may-allocate claim
is tested through the resulting omission of that precise allocation root point.
The canonical check rejects the omission, so bitmap validation cannot be bypassed.

All observation-only projects retain the same ordinary compiler modules and
record their entry/probe or trap/counter changes. Runtime graphs, streams,
identities and failed exploratory predecessors remain preserved in the local
evidence set. Isolation timings are functional observations, not performance
samples. Inherited performance regression, all preliminary cells, formal budget
adoption and fresh formal measurement are pending. This is not whole-version
acceptance or a release record.
