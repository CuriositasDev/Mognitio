# Scanner allocation reduction

The scanner constructs diagnostic spans only on error paths. Successful scalar
scanning uses primitive source positions instead of allocating a temporary span
for every character. Unicode escape digits use direct branches rather than
creating an iterator over the hexadecimal alphabet for each digit.

The [observations](v1.6.0-lexer-allocation.json) identify the compiler source and
probe. All 63 paired boundary cases preserve exit status, stdout and stderr,
including uppercase hexadecimal escapes and source sizes through 65,536 scalars.
The probe also passes 41 value cases, 26 I/O observations, six module cases and
17 collection-before-allocation cases. The complete normal suite passes
236 groups, 605,733 assertions, 1,316 native processes and subsequent Python
integrations.

The compiler and normal-suite sources were tested at the recorded commit.
The following record commit corrects the uppercase test fixture to exercise
an actual Unicode escape; all 63 paired cases were rerun after that correction.

This allocation reduction does not establish complete C1 acceptance or a formal
performance budget. The public driver remains unchanged, and final activation,
same-candidate validation and release remain pending.

~~~sh
python3 tests/mgnc/v160-native-runtime.py --seed VERIFIED_SEED/bin/mgn --output NEW_RUNTIME

sbcl --noinform --script scripts/test.lisp

~~~
