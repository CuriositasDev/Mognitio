# Managed-slot root projection

Wide scalar-heavy bodies need few managed roots but previously retained live
vectors for every scalar slot. The planner now assigns compact analysis IDs to
managed slots, projects reads/writes onto that domain, and expands only consumed
frame maps back to original slot numbers. Scalar slots, stack layout, operation
positions and emitted bitmap format are unchanged.

Projection commutes with the independent use/kill equations for each managed bit.
The producer retains the backward worklist; the checker still uses original IR
slot numbers and its separate read-origin graph. The original forward-path
oracle is also unchanged. No verifier or root requirement was removed.

[Identity and observations](v1.6.0-root-projection.json) include the source,
immutable seed and generated compiler. Tests freeze eight additional sparse or
all-scalar graphs at 4,097 / 65,537 slots before changing the producer. Both
implementations agree with independent oracles on 152 graphs / 456 bitmap
mutants. The 52-frame / 76-descriptor tests reject all 17 layout/root mutants;
the permuted-block DAG and old-order mutant also pass.

All 90 native runtime checks pass. The 41 generated value images are byte-for-byte
equal to the prior compiler's images. The complete normal suite and inherited,
I/O-fault, userland-isolation, lifetime and 78 public-cost observations pass;
counts are retained in the JSON record.

The fixed 64 KiB List now builds in 691.24 seconds with 1,472,208,896 peak RSS
bytes and executes with its independent expected exit 104 and empty streams.
The previous candidate was cut off at 900 seconds and reached 3,886,825,472
observed RSS bytes. These are exploratory runs alongside other verification,
not adopted formal performance budgets.
