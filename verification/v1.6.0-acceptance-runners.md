# Full-backend acceptance runners

The full backend needs repeatable evidence for scale, publication, module order
and independent execution. These runners retain failed and unrun cells, bind
input/compiler hashes, and use separate output directories for each attempt.

The scale runner checks exact input membership before and after builds, including
late inventory failures. Controlled observations cover successful builds, failed
builds, timeout, input mutation, new source membership, compiler mutation and
partial selection. Four independent malformed ELF headers are rejected.

The isolation runner fixes the build umask to 0022 before requiring mode 0755.
An initial run inherited umask 0002 and correctly failed that assertion with mode
0775. This was a harness configuration error; no compiler behavior was changed.
The corrected runs include immutable userland inventories.
