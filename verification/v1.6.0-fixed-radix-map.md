# Persistent radix map allocation and specialization checks

The inherited native-build measurement failed three combined 1,000-declaration
cells at roughly 36-37 seconds against the unchanged 30-second criterion.
Profiling found repeated map path allocations and specialization verifier scans.

IntMap now uses ten fixed-field four-way radix nodes instead of child Lists.
Empty subtrees are immutable shared values; updates rebuild only their ten-node
path. Exact large Int64 key fallback, negative-key errors, missing sentinel and
persistent snapshots are unchanged. The specialization verifier builds its own
source-body index, then independently checks complete bindings within that body.
It does not trust producer deduplication.
