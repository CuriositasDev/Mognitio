were explicitly accepted on 2026-10-24, together with authorization to release.

results, raw-restoration identities and historical unsuccessful attempts.

assets on the immutable v1.7.0 release.

## Source and distribution gates

Run the complete normal suite at the exact release candidate. Verify the full
tracked checksum manifest and candidate/tagged source archives. Rebuild mgnc
from archived source with the verified qualified seed and require byte identity
with A before inheriting functional, isolation and performance evidence.
Re-run named-contract, metadata and assertion native checks.

Build one formal normal-toolchain payload from clean main and the locked Ubuntu
image, runtime, core and notice. Package the identical payload into Debian and
offline archives. Verify identity, bytes, permissions, installer failure/recovery,
protocol/analysis/projection/tokens, signing/trust and the unchanged consumer.
Verify real 1.6.0 offline upgrades on Ubuntu 24.04 and 26.04.

Freeze the draft assets, dispatch production signing with the exact manifest
hash and independently verify all downloaded bytes and signatures. Require the
signed package workflow to pass both supported userlands, including execution
as an unrelated unprivileged user after root installation, before publication.
Publish APT through its reviewed append-only registry and verify public HTTPS
signed-by upgrade, run/build/test/LSP, reinstall/remove/purge and standalone use.

## Boundaries

Only mgn and mognitio-lsp are installed. mgnc remains experimental and source-built.
Repeated B1 self-generation belongs to version 1.8; ordinary CLI, test runner,
LSP and distribution replacement belongs to version 1.9. The normal toolchain
and accepted seed retain separate identities. The known ordinary-toolchain
unused-imported-witness limitation is not represented as fixed here.

Linux amd64 / Ubuntu 24.04 and 26.04 are the package matrix. Namespace tests share
the host kernel. VS Code extension and Levi releases are separate projects.
Retain exact commits, frozen artifacts, workflows and raw release evidence in
persistent storage, with publication recorded separately from acceptance.
