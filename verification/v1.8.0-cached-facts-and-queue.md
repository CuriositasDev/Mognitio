# Cached fact reads and queue membership

The dataflow verifier previously cleared a persistent queue-membership map on
every dequeue and wrapped successful bitmap lookups in another Result. It also
read the immutable base word before selecting an already pending edited word.
These operations created avoidable temporary values during compilation.

Queue membership now records each block's last one-based queue position. A
position greater than the consumed prefix means pending; re-enqueueing records
the new position. Initial reachability stores positions in the same traversal
order. Edge order, duplicate suppression, repeated visits and diagnostics remain
unchanged, including self-edges after the current entry is consumed.

Bitmap equality inspects each original lookup result, retaining reverse index
order, the length check and left-before-right error handling. Pending-word reads
skip the base lookup only for a matching, nonnegative index within the immutable
base length. Otherwise the original lookup and diagnostic occur before the bit
check. Definitions, old snapshots and error spans remain unchanged.

## Validation

The identical product source passed the existing bitmap and dataflow oracles
under the seed, native and hosted compilers. Edit sequences retain 18 sequences,
180 writes and 3,759 reads; six additional manually constructed WordEdit cases
check nine reads, including invalid cached indices and diagnostic ordering.
The same boundary cases follow the original sequences in the repository,\nso existing mutation failures retain their first-failure order. Two existing
mutation substitutions follow the changed expressions and keep their original
first-failure expectations.

Fresh native generations and hosted/native output agreed byte-for-byte. Thirteen
native regression jobs passed, followed by a fixed 16-case, 96-start comparison.
All prototype cases fit the unchanged numeric budgets and single-start guards;
all 42 generated programs matched expected bytes and executable modes. The
baseline hosted width-64 build exceeded its 20-second median budget and remains
failed. Some other prototype cases were slower; no universal speedup is claimed.

These are scoped implementation checks, not formal P0/P1 results. Earlier
failures remain recorded. Acceptance of a fresh candidate from integrated main,
full performance coverage and final archive restoration remain separate gates.
