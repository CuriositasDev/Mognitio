# Mognitio 1.6.0 acceptance and release validation

All version 1.6 specification, design, implementation and performance stages
were explicitly accepted on 2026-10-20, together with authorization to release.
The [final acceptance](v1.6.0-final-acceptance.md) and separately identified
[evidence recovery](v1.6.0-evidence-recovery.md) retain their original identities.
This record defines release gates; publication is established by the signed
assets on the immutable v1.6.0 release.

All 91 conformance cases, 11 workloads and 16 internal review cells are accepted.
The [formal measurements](v1.6.0-formal-performance.md) cover 103 cells / 412
samples. All 301 inherited performance cells retain their fixed criteria.
The [recovery run](v1.6.0-evidence-recovery.md) supplements missing historical raw
logs with fresh observations; it does not claim to restore the lost files.

## Source and distribution gates

Run the complete normal suite at the exact release candidate. Verify the full
tracked checksum manifest and candidate/tagged source archives. Rebuild mgnc
from the archived source with verified S10 and require byte identity with A
before inheriting its complete functional, isolation and performance evidence.
Re-run conformance, native/runtime review and measurement harness checks.

Build one formal normal-toolchain payload from clean main and the locked Ubuntu
image, runtime, core and notice. Package that identical payload into Debian and
offline archives. Verify identity, bytes, permissions, installer failure/recovery,
protocol/analysis/projection/tokens, signing/trust and the unchanged consumer.
Verify real 1.5.0 offline upgrades on Ubuntu 24.04 and 26.04.

Freeze the draft assets, dispatch production signing with the exact manifest
hash and independently verify all downloaded bytes and signatures. Require the
signed package workflow to pass both supported userlands, including execution
as an unrelated unprivileged user after root installation, before publication.
Publish APT through its reviewed append-only registry and verify public HTTPS
signed-by upgrade, run/build/test/LSP, reinstall/remove/purge and standalone use.

## Boundaries

Only mgn and mognitio-lsp are installed. mgnc remains experimental and source-built;
its complete N160 profile does not establish full-language native support or
whole-compiler self-rebuilding. The normal toolchain and accepted seeds keep
separate identities. The known unused-imported-witness limitation remains tracked
by the prior release and is not represented as fixed here.

Linux amd64 / Ubuntu 24.04 and 26.04 are the package matrix. Namespace tests share
the host kernel. VS Code extension and Levi releases are separate projects.
Retain exact commits, frozen artifacts, workflows and raw release evidence in
persistent storage, with publication recorded separately from acceptance.
