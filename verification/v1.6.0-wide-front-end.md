# Wide compiler input traversal

The fixed 64 KiB List input exposed repeated page-chain indexing, reverse List
indexing and rescanning of completed operand prefixes. Paged tables now retain
a second-level index, while preserving their sequential page view and persistent
snapshots. Expression frames index pending children once and retain cumulative
normal completion for ordinary operands. Conditional arms, function entry and
loop-local completion keep their separate rules.

[Identity and checks](v1.6.0-wide-front-end.json) bind the tested source and the
full-backend probe. A 65,537-value oracle covers page/group boundaries, replacement,
old snapshots, invalid indexes and agreement with sequential iteration; both
stale-index mutants are rejected. Fourteen fixed wide-value cases preserve order,
return behavior and later type errors. The unchanged 64 KiB input passes check
in 30.83 seconds in an exploratory run with concurrent verification work.

The v1.6 flow/conformance adapters preserve v1.5 fixture source and diagnostic
checks. Five flow and ten conformance builds formerly refused by the scalar
backend are now expected to succeed under N160, with independent runtime checks.
Fixed-width numeric and path-inspection exclusions remain intact.

Validation at the recorded compiler source includes the complete normal suite
(242 groups, 1,889,890 assertions, 1,324 native processes and all subsequent
integrations), 90 full-backend runtime checks, 59 semantic cases, 36 flow cases /
159 checks, and 149 conformance checks. No public contract changed.
