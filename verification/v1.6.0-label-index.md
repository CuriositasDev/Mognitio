# Native relocation label index

Large List builds spent substantial time scanning and rebuilding one of 64 label
buckets. The encoder now uses the existing exact integer map for label lookup and
duplicate detection. Record validation, offsets, relocation bytes and the ELF
format are unchanged.

The fixture was frozen before the implementation. Independent Python byte oracles
cover 128 and 8192 colliding label IDs, relative forward and absolute backward
references, and sparse IDs across the radix boundary and near the signed integer
limit. Nine negative vectors retain exact diagnostics. Both implementations pass
all vectors; exploratory probe runtime changes from 4.64 s to 0.17 s.
The existing 19 x64 vectors and executable ELF check also pass.

Compiler source tested: 27b0fb3e65ef22c216b244b8a2023e846fd8439e.
The [identity and observations](v1.6.0-label-index.json) bind the accepted S7,
candidate A, input manifest, byte oracles, normal-suite log hash and observations.
This probe still uses the separately reviewed full-backend Driver; public Driver
activation is pending.

The 64 KiB List build finishes in 187.77 s with peak RSS 1,471,848,448 bytes,
compared with 691.24 s before this change. Its 4,055,624-byte artifact is identical
to the previous artifact and executes with expected exit 104 and empty streams.
All 41 small native value artifacts are also byte-identical. These are exploratory
observations with other verification running, not formal performance samples.
An earlier invocation used a nonexistent fixture directory and exited 2; it is
retained separately and is not included as a workload observation.

Validation at the tested source revision:

- Complete 34-case scale matrix; no skipped or unsuccessful case.
- Native runtime 90 observations; runtime components 29 cases and five raw faults.
- Public operation-cost observations: 78 cases.
- Extended, historical native, inherited semantics, profile, failure/ownership,
  publication boundaries, two Ubuntu isolation environments, and lifetime gates.
- Wide operands 14 cases, semantics 59 checks, flow 159 checks, conformance 149
  checks, and 11 lower-command cases.
- Normal toolchain: 242 groups, 1,889,890 assertions, 1,324 native processes;
  all subsequent Python integration checks; diff whitespace check.

A separate exploratory check on the immutable old v1.5 C1 input exits correctly
but reaches 336,273,408 bytes RSS, exceeding its retained 256 MiB budget.
This is an unresolved regression, not accepted performance. The accepted
criterion is unchanged. Final whole-version acceptance requires fixing it,
freezing the final C1/A, completing all preliminary cells, separately adopting
new performance budgets, and collecting fresh formal observations.
No public Specification or Design contract changes in this increment.
