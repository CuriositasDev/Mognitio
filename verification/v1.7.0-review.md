# Version 1.7 implementation review

The integrated version 1.7 implementation has completed its defined acceptance
gates and is ready for release-readiness code review. This record identifies the
fixed source, independent checks and final evidence. It does not announce or
authorize a release.

## Revisions and scope

- Released baseline: `v1.6.0`, commit `a3d1ec09c023f09e6f6da526fa5cf64f030c5e80`.
- Implemented source: `c0bf8be823a0ba7b20493993f1e6031cf905b1d1`.
- Full-suite tested head: `ff9f3a0ccbab93bbd023640d360f7504e9d5949c`.
- Tested and integrated tree: `3a3fcbfad127eae349e18d2bc16efd1e4cd03003`.
- README-only follow-up: `81d9cec7ab2f4a8fb14f793bb5a687a3df50737e`.

The [complete baseline-to-review diff](https://github.com/ProjectCuriositas/Mognitio/compare/v1.6.0...c0bf8be823a0ba7b20493993f1e6031cf905b1d1)
contains 304 files, 11,251 added lines and 400 removed lines. Generated helper
tables, independent oracles and historical verification records are included.
The acceptance checkout remains fixed at the implemented source revision.

The experimental compiler supports the expanded native profile described in
[its README](../compiler/mgnc/README.md). Normal test-declaration initialization
is distinct from running a test suite. Repeated self-generation and replacing
the ordinary CLI, test runner, language server or distribution are outside this
checkpoint's scope. The ordinary toolchain retains its existing public surface.

## Retained unsuccessful attempts

Failed candidates and harness attempts remain retained. Bubblewrap reaper and
umask corrections affect test execution only; expectations and production code
were not relaxed. A later userland setup attempt failed before program startup
because the read-only root lacked two bind targets. Adding empty target locations
preserved every original userland file; the final closure links the 14 earlier
successful observations and seven corrected remainder observations to their
execution records. Both failed whole-isolation attempts remain recorded.

The first new preliminary series also exposed a harness expectation error: it
required mode 0755 for every generated executable, while the bootstrap seed
explicitly emits A with mode 0700. A's bytes and exit/streams were correct.
That attempt and the interrupted following measurement remain recorded as
failed/aborted. A separate full preliminary series uses producer-specific mode
checks: 0700 for bootstrap A and 0755 for native outputs under umask 0022.
Commands, fixtures, artifact hashes, sample counts and exploration guards are
unchanged. None of the interrupted measurements substitutes for a fresh sample.

The mode-corrected whole shard completed 17 cells, but its extension shard
finished with 108 passed, 36 failed and three not run. The failures exposed
three harness defects: RUN expansion consumed the RUNTIME prefix; replaying a
publication oracle deleted the already-measured output; and padded decimal
fixtures violated the language's leading-zero rule. Corrected fixtures use
long valid strings, late decimal suffixes, full-token numeric range rejection
and late string escapes. They cover 4,096, 16,384 and 65,536 scalars and add
18 paired negative cells. Compiler and runtime source are unchanged.

Separately, a controlled experiment showed that child kernel RSS inherited a
measurement-launcher floor that grew with the controller's memory history.
The corrected observer starts a fresh worker for every sample, preserves the
fixed worker floor, and records kernel peak, sampler peak, missing samples,
sampled child presence and final reaping separately. RSS aggregation uses the
larger kernel/sampler peak. A missing short-run sample is null, never zero.
Ten observer controls, 38 focused fixture/runtime checks, 34 evaluator checks,
60 formal-runner checks and 15 adoption checks passed. Later artifact-binding
controls extended the evaluator checks to 38. Old observations remain
retained; the new 182-cell preliminary series and later fresh formal series
used the corrected policy and completed successfully. The earlier 401 inherited gates retain their original
measurement method and criteria.

A preliminary stop guard is not a formal pass threshold.
No tag, release or package publication has been performed for this checkpoint.

The archive metadata preflight initially rejected an intentional non-UTF-8
filename. A separate serializer correction preserves POSIX byte names as JSON
escapes without changing the original fixtures. Seven archive controls, including
nested byte names, links, tamper rejection and permission restoration, passed
before the final archive. The failed preflight remains retained.

The first post-adoption reclamation collector stopped because rebuilding the
same source at a different path changed embedded diagnostic metadata and thus
the program hash. That failed collector and its raw observations are retained.
A separate fresh 18-observation run builds from the original frozen source path
and preserves full source/program hash equality and all adopted bounds. Seven
identity controls and 13 evaluator binding controls passed. The already-complete
182-cell wall/RSS series is unchanged and independently bound to the final closure.
